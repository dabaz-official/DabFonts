A → B/C 的差别 全部发生在共用码位上。引号在 A 里是 53.7px 宽（苹方），在 B/C 里是 42.9px（Inter）； 省略号从居中的六点变成左下三点；破折号从两枚全角连排变成 Inter 的西文 em dash。
B 与 C 的差别 肉眼为零。实测每个字符宽度完全一致——C 并没有改变渲染，它改变的是 分发方式：一个文件、一套度量、不依赖 unicode-range 拼接。
中文标点已半角化 C 里 。 ， 、 仍由 Noto 提供，但 advance 已从 1000 改成 500 ——用的是 Noto 自带的 hwid / halt 参数，直接烘进字形。 Inter 没有这些字符，所以它们只能来自中文字体。
字体来源：Inter 4.001（OFL 1.1，Inter Project Authors）、Noto Sans SC 2.004（OFL 1.1，Adobe / Google，保留字体名 Source）。 合并产物 DabFonts 同样以 OFL 1.1 发布，仅用于个人非商业项目。 最后一行里的 阿拉伯文 / 天城文 / 韩文 / 泰文 / 扩展 B 汉字 不在字体覆盖范围内，由系统字体接管——这正是"用不了则用系统字体"的表现。
构建注记：合并后已从 Noto 侧移除 locl 特性。它在 lang=zh-CN 下会自动启用，把 668 个拉丁字形替换成 Noto 自带版本， 实测使 A 的宽度从 686 掉到 608——不处理的话，Inter 等于白合并。
