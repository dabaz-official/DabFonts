# History snapshots

Each directory preserves the build from before a change to glyph metrics, for comparison and rollback.

| Directory | Han | Punctuation | Han advance | Use |
|---|---|---|---|---|
| `v1-fullwidth/` | 20,976 (full set) | Full-width 1000 | 1000 | The “old” column in `demo/punct.html` |
| `v2-halfwidth-unscaled/` | 3,755 (GB2312 level 1) | Half-width 500 | 1000 | The “before scale” column in `demo/scale.html` |

The current build (`../dist/DabSans-*`, `../dist/DabMono-*`) is v2 plus the 0.94 CJK scale (advance 940).

v1 keeps TTF only (the web comparison subsets are generated by `scripts/build_web_assets.py`); v2 keeps TTF and woff2.

Rollback: copy the files from the chosen directory into `dist/`; `scripts/build_web_assets.py` regenerates the page subsets.
